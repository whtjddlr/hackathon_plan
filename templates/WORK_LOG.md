# 작업·결정·검증 기록 - 제공 환경 내부 전용

중요한 변화만 짧게 기록한다. 사이클마다 검증 후 1~3줄이면 충분하며, 아래 표를 모두 채우려 시간을 쓰지 않는다. 과제 내용·로그를 외부로 공유하지 않는다.

## 사이클 체크포인트

`목표 하나 / 예산 5~10분 / 실제 결과·근거 / 남은 위험 / 사용자 다음 선택`

예산 초과·미완료도 사실대로 남긴다. 다음 작업을 자동 시작하거나 전체 제한 시간을 채우지 않는다.
