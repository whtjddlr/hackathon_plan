# 작업·결정·검증 기록 - 제공 환경 내부 전용

중요한 변화만 짧게 기록한다. 작업 중에는 기록에 시간을 쓰기보다 검증 후 1~3줄을 남긴다. 과제 내용·로그를 외부로 공유하지 않는다.

기대값을 구현의 출력에서 복사하지 않는다. 실패를 숨기지 않고 수정 후 같은 사례로 재검증한다. 수동 UI 관찰 전에는 통과를 기록하지 않는다.
