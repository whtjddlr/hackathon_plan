# 작업 계획 - 제공 작업 환경 안에서만 작성

빈 양식이다. 공식 필수 문서가 있으면 그 양식·파일명을 우선한다. 이 공개 저장소 자체를 작업 기록 저장소로 사용하지 않는다.

## 목표와 제약

- 목표 한 문장:
- 근거가 되는 과제 안내/파일:
- 필수 산출물과 경로:
- 현재 남은 시간 / 제출·후속 단계에 남길 여유:
- 변경하지 않을 것 / 하지 않을 부가 기능:

## 요구와 판정

| ID | P0/P1 | 요구와 출처 | 수용 기준 | 독립 기대값의 근거 | 검증 방법 | 상태 |
|---|---|---|---|---|---|---|
| R1 | | | | | | 미착수 |

상태는 `미착수 / 구현 중 / 미검증 / 통과 / 실패 / 확인 불가`로 구분한다.

## 불확실성

| 사실/가정/미확인 | 내용 | 영향 | 확인 대상/방법 | 확인 결과 |
|---|---|---|---|---|
| | | | | |

## 최소 설계

- 입력 → 핵심 처리 → 결과:
- 기존 스택/파일 중 재사용할 것:
- 첫 실행 명령과 최소 입력:
- 가장 큰 실패 위험과 대응:

## 이번 사이클 하나만

- 목표 하나 / 관련 요구 ID:
- 범위 / 운영 예산 5분 또는 10분:
- 완료 판정 / 독립 기대값 / 검증 방법:
- 결과·근거·남은 위험:
- 사용자 다음 선택: 계속 / 범위 축소 / 방향 변경 / 최종 점검

다음 사이클을 자동 시작하지 않는다. 모든 P0·필수 검증·문서·저장이 완료되면 추가 기능 대신 제출 점검으로 간다.
