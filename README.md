# 180분 AI 해커톤 플레이북

**많이 만들기보다, 요구를 정확히 읽고 작동하는 핵심을 검증해서 제출한다.**

공개 준비용 지침·프롬프트·빈 템플릿이다. 특정 과제의 정답, 완성 앱, 제출 답안은 포함하지 않는다. 공식 운영 지침을 대체하지 않으며, 최신 공지와 실제 과제 안내가 항상 우선한다.

## 바로 쓰는 순서

1. 시험 **전에** [체크리스트](CHECKLISTS.md)를 읽고 장비와 허용 범위를 점검한다.
2. 제공된 작업 환경 안에서, 허용된 AI에게 이 공개 저장소를 읽게 한다. 다운로드한 파일·스크립트는 검토 없이 실행하지 않는다.
3. 먼저 **실제 과제 README·기존 지침·필수 제출물**을 읽고, [시작 프롬프트](PROMPTS.md#1-시작-요구와-완료-조건)를 사용한다.
4. [180분 운영표](PLAYBOOK.md)를 따라 핵심 흐름 하나를 끝까지 완성하고 검증한다.
5. [제출 점검](CHECKLISTS.md#제출-직전) 후 플랫폼에서 제출한다. 제출물 확정은 전체 응시 완료가 아니다.

공개 자료 가져오기가 허용된 환경에서 사용할 저장소 주소:

```text
https://github.com/whtjddlr/hackathon_plan.git
```

이 저장소를 참조 폴더에 가져와 `AGENTS.md`와 필요한 문서만 읽게 한다. 과제 루트의 기존 `AGENTS.md`, README, 코드를 덮어쓰지 않는다. 가져온 **commit SHA와 사용한 파일**은 제공 작업 환경 안에 기록한다.

## 가장 중요한 다섯 가지

- **P0 = 실제 필수 요구.** 보기 좋은 부가 기능보다 우선한다.
- **일찍 끝까지 연결.** 입력→처리→결과의 최소 흐름을 먼저 만든다.
- **기대값을 독립적으로 정한다.** 현재 코드의 출력으로 정답을 만들지 않는다.
- **근거를 남긴다.** 결정·테스트·실패·한계를 짧게 기록한다.
- **마지막 10분은 제출.** 새 기능을 만들거나 큰 리팩터링을 하지 않는다.

**공개 준비 저장소는 읽기용이다.** 문제·제공 파일·작업 결과·로그·개인 링크·키를 여기에 넣거나 외부로 보내지 않는다. 사용한 저장소는 안내된 결과 통지 시점까지 공개 상태를 유지한다. 외부 자료로 결과물을 통째로 대체하지 않는다.

외부 AI·개인 API 키·Computer Use·제한 우회는 사용하지 않는다. 제공된 Codex와 승인된 모델만 사용하고, Codex를 업데이트하지 않는다. MCP는 기본 **0개**, 병렬 에이전트도 기본 **없음**이다.

## 외부 코드가 정말 필요할 때

기존 환경의 표준 라이브러리/설치된 도구를 먼저 쓴다. 새 자료는 공식 저장소와 라이선스를 확인하고 commit 또는 버전을 고정한다. 출처·사용 범위는 [출처 기록 양식](templates/PROVENANCE.tsv)에 남기고 필요한 저작권/라이선스 고지를 보존한다. 라이선스 불명, 출처 불명, 원격 스크립트 즉시 실행, 불필요한 권한·외부 전송이 필요한 도구는 피한다.

이 자료는 독자 작성한 일반 절차이며 외부 코드·패키지를 번들하지 않는다. 라이선스는 [MIT](LICENSE).
